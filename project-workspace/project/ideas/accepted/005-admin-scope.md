# Admin Scope

## Decision

The admin application is only a placeholder in this foundation.

It is a separate web application, but it is not a functional admin panel yet.

## Explicit consequence

The generated code must not implement CRUD, authentication, authorization, user management, roles, or admin business workflows in this foundation.

## Spec mapping

This decision must be represented in:

- `spec/02-applications.md`;
- `spec/06-non-goals.md`.
