# Runtime Modes

## Supported Modes

The system must support:

- development mode;
- production mode.

## Runtime Requirement

In both supported modes, the system must run with the five runtime components defined in `spec/01-architecture.md`:

1. site frontend;
2. site backend;
3. admin frontend;
4. admin backend;
5. shared database.
