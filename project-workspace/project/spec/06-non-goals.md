# Non-Goals

## Admin Placeholder Limits

The admin application is not a functional admin panel in this foundation.

The generated code must not implement:

- CRUD;
- authentication;
- authorization;
- user management;
- roles;
- admin business workflows.

## Foundation Out of Scope

The following are out of scope for this foundation:

- authentication;
- authorization;
- CRUD;
- user management;
- roles and permissions;
- admin business functionality;
- public catalog;
- item cards;
- search;
- production business data model;
- business migrations;
- external APIs.
