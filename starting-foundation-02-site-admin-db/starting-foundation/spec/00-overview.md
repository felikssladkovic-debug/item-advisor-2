# Overview

Generate a minimal multi-application web system.

The system must include:

- site frontend;
- site backend;
- admin frontend;
- admin backend;
- shared database.

The generated project must be runnable in:

- development mode;
- production mode.

The application must prove database connectivity from both backends.
