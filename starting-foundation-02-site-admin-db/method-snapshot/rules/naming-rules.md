# Naming Rules

## Purpose

Keep names stable, readable, and script-checkable.

## File Names

Use lowercase kebab-case for files:

```text
workflow-overview.md
```

## Document IDs

Use path-derived dot notation:

```text
rules.workflow-overview
```
