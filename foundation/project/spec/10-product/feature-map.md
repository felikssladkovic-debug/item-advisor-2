# Feature Map

## F-01 Authentication

- Login with email and password.
- Logout current session.
- Restore current session on page refresh.

## F-02 Authorization

- Grant access based on `role`.
- Allow `manager` to access admin users page.
- Deny `user` access to admin users page.

## F-03 Site Page

- Show a welcome view for authenticated users.
- Show current user email and role.

## F-04 Admin Users Page

- Show a tabular list of known users.
- Include email and role for each user.
