# Product Overview

## Purpose

Provide the smallest usable foundation for an internal application with login, role-aware navigation, a protected site page, and a manager-only user administration view.

## Primary Users

- Manager
- Regular user

## Product Behavior

- A visitor can log in using email and password.
- After login, the user lands on the site page.
- The site page shows the authenticated user identity and available navigation.
- A manager can open the admin users page and view the user list.
- A regular user cannot open the admin users page.
