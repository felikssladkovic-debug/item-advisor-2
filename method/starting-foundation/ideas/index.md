# Ideas

This folder is for the first business/project idea documents.

Use [[templates.business-idea-template]] when creating concrete idea files.

## Expected content

- project purpose;
- users or stakeholders;
- problem being solved;
- initial scope;
- explicit non-goals.

## Not for

- implementation details;
- framework choices;
- generated code;
- deployment instructions.
