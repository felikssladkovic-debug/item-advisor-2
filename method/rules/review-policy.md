# review-policy

## Перед генерацией кода
- Понятна цель первой версии.
- Понятны ограничения.
- Есть минимальные acceptance criteria.

## После генерации кода
- Код соответствует spec.
- Нет лишних подсистем, не описанных в spec.
- Есть инструкция запуска.
- Есть минимальная проверка работоспособности.
