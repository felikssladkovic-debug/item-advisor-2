# human-llm-codex-roles

## Human
Задает цели, принимает продуктовые решения, утверждает компромиссы.

## LLM consultant
Помогает формулировать идеи, spec, архитектуру, prompts, review.

## Codex
Работает в репозитории: создает/меняет файлы, запускает проверки, поддерживает трассировку.

## Запрет
Codex не должен молча превращать barebone в конкретный стек без явного решения в spec.
