# Starting Foundation

This folder is the pre-created scaffold that Codex must fill, not invent from scratch.

It is intentionally project-neutral: no assumption about website, admin panel, backend, frontend, database, or deployment model.

## Folders

- [[starting-foundation.ideas.index]] — initial business/project intent.
- [[starting-foundation.spec.index]] — initial specification documents.
- [[starting-foundation.decisions.index]] — early decisions that shape the project.
- [[starting-foundation.change-requests.index]] — planned deltas after the first version exists.

## Rule

Codex may add project-specific files inside these folders, but must preserve the folder names and update the method-wiki links when new method documents are added.
