# Layers and Flow

## Purpose

Describe the conceptual layers used by the method.

## Layers

```text
idea layer
spec layer
prompt layer
code layer
test/check layer
runtime observation layer
```

A project can start with very thin layers, but it should not collapse all decisions directly into code.
